# 指标与对照口径

本页引用项目已保存结果，本次打包不重新运行真实模型评测，也不把这些数字视为线上业务指标。

## 历史 v3 检索

34 条项目合成题（22 有答案、12 无答案），项目 Agent 编写，未经独立人工复核。
词法 RRF → 门控词法+Qwen 向量：Hit@5 68.18%→86.36%，MRR 0.6591→0.8409；无答案不返回证据 83.33%→75.00%。
原 JSON 的 Recall@5 名称已更正为 Hit@5，代码按“至少命中一个”统计。当时每题一个相关片段，数值恰好相同，不证明多证据完整召回。
这个对比不是相对 Haystack 的提升，也不测生成回答正确性。

## 产品范围消融（简历采用）

同一 RRF 检索配置、相同公开用户/订单产品信息，关闭或开启产品过滤。
22 条合成作用域正例，13 条带已确认订单产品，9 条有明确型号文本。

| 指标 | 无产品过滤 | 有产品过滤 |
|---|---:|---:|
| 跨产品证据占比 | 70/110=63.64% | 0/71=0% |
| Hit@1 | 13/22=59.09% | 18/22=81.82% |

证据占比的分母是实际返回证据数，不是查询数。这不测 LLM 产品识别准确率，也不证明 Haystack 不支持过滤。

## 成熟基线与负结果

项目已搭建 Haystack BM25、dense、RRF 及固定 CrossEncoder 的独立基线与消融，按问题族隔离开发/测试。
首轮共 242 条场景、38 个问题族；各项指标使用自己的子集，不能用 242 替换 22 或 71 的分母。
纯向量在一些设置上更强；重排及证据门槛可能提高拦截但损失召回，不能宣称全面优于标准方法。
后续证据充分性审核属于离线实验，未经在线验收不能表述为默认生产路径。
