# 升级与人工接续

无法自行恢复、需进一步材料审核或用户要求专员时，梳理目标、确认产品、设备、已试步骤、反馈、图片引用、购买核验与未解决问题。

1. 用 `propose_escalation` 创建冻结内容的草案，呈现接收方、会发送的材料、下一步和缺项。
2. 用户确认绑定草案版本；草案变化必须使旧确认失效。模型只能提草案，不能自行批准、提交或填写用户反馈。
3. 实际提交、动作幂等及结果对账由运行时完成。回执丢失时按原动作 ID 查询，不以新 ID 重复提交。
4. 根据真实回执说明状态：草案、等待确认、提交结果未知、已受理、人工处理中、已解决分别表达。已受理不能称设备已经修复。
5. 人工接续共享同一任务证据和未解决事项，保留过程来源。模拟后端必须明确说明是模拟工单，不能声称送达安克官方客服。

情绪和紧迫性影响沟通与优先级，不跳过产品、权限、证据版本和提交校验。再次提问前先查看已有信息。
